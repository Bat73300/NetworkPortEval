# Example flow imports

These CSV files are starting points for macOS network checks in NetworkPortEval. Imported flows are unchecked; select only the destinations you intend to test.

- [Apple enterprise services for Mac](NetworkPortEval-Mac-Apple-Enterprise-Flows.csv) — 99 candidate Mac destinations from [Apple’s enterprise network host and port list](https://support.apple.com/fr-fr/101555). Entries for iPhone, iPad, Apple TV and other non-Mac platforms are excluded. Apple wildcard destinations are omitted because the importer requires a concrete hostname. Imported flows start unchecked; a TCP result checks reachability only, and UDP silence is inconclusive.
- [Adobe Creative Cloud endpoints](NetworkPortEval-Mac-Adobe-Creative-Cloud-Flows.csv) — 449 rows normalized from Adobe's public [network endpoints documentation](https://helpx.adobe.com/fr/business/enterprise/manage-services/configure-services/network-endpoints.html?lk#all-adobe-services), reviewed on 2026-09-29. The source does not define the platform or most ports. TCP 443 is therefore an assumption for entries without a listed port; explicit ports and the port implied by an explicit URL scheme are preserved. Wildcard hosts are omitted. These are connectivity probes, not TLS, HTTP, WebSocket or Adobe application checks. Importing the file does not select its flows; start with a small subset.
- [Microsoft 365 starter flows](NetworkPortEval-Mac-Microsoft-365-Starter-Flows.csv) - six small HTTPS examples for common Microsoft 365 entry points. Based on Microsoft's [Microsoft 365 URLs and IP address ranges](https://learn.microsoft.com/en-us/microsoft-365/enterprise/urls-and-ip-address-ranges?view=o365-worldwide), reviewed on 2026-09-29. This is not a tenant-specific or complete Microsoft 365 allowlist; add your organization's exact tenant hosts and use Microsoft's endpoint web service for current firewall policy.
- [Jamf Cloud for Mac](NetworkPortEval-Mac-Jamf-Cloud-Flows.csv) — 22 HTTPS probes: four Jamf Cloud Distribution Service (JCDS) endpoints for each of five regions, plus shared Sentry and App Installers services. Regional JCDS hosts come from Jamf’s [public IP/domain list](https://learn.jamf.com/r/en-US/jamf-ip-address-list/Jamf_Public_IP_Address_List); the two shared services are identified in Jamf’s [network ports article](https://learn.jamf.com/r/fr-FR/technical-articles/Network_Ports_Used_by_Jamf_Pro). Select only the region used by your Jamf tenant, and add your organization’s exact Jamf Pro Cloud hostname separately on HTTPS 443—the tenant-specific hostname is not included. Wildcard Remote Assist hosts are omitted. These probes check TLS certificate/hostname and HTTP `HEAD /`; they do not confirm MDM enrollment, agent check-in, APNs, package authorization/download or feature health.
- [Sandbox UDP/DNS test](NetworkPortEval-Mac-Sandbox-UDP-DNS-Test.csv) — one DNS query to `1.1.1.1:53` with an example.com A-record payload for the experimental App Sandbox build. It tests whether a UDP response is received; it does not validate the DNS answer contents. Import into the sandbox build, select only this flow, and interpret silence as inconclusive.

All sample flows start unchecked. Review current vendor guidance and your organization’s requirements before using a sample to change firewall or proxy rules. These are connectivity examples, not complete or authoritative allowlists.
