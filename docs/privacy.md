# NetworkPortEval Privacy Notice

NetworkPortEval is a Mac network connectivity diagnostic tool published by BC performances (Baptiste CRESTANI).

The application stores settings, templates, email contacts, and reports locally on the Mac. Reports can include destination names and ports, test results, timestamps, local IP addresses, the local network interface MAC address, interface and VPN information, configured DNS resolver addresses, HTTPS certificate details, and the public egress IP. The application does not send saved reports or the local address book to BC performances, and it does not operate a NetworkPortEval server.

Before a manual run, the user can choose whether to include optional checks to Google, Apple, and ipify. Each scheduled run stores its own choice. Those services receive the public source IP and ordinary connection metadata for the requests. The destinations selected by the user also receive the connection traffic required for the selected TCP, UDP, or HTTPS test. Use the application only on destinations you are authorized to test.

The application has no account, analytics, advertising, or telemetry service. Reports and exported files are not encrypted by the application. Users control their local files, backups, exports, and sharing. Reports and saved contacts can be deleted in the application; exported copies and backups must be removed separately.

When the user chooses to email a report, NetworkPortEval hands the selected addresses and a CSV attachment to macOS’s email composition service. The user reviews and sends the message in the configured mail application; NetworkPortEval does not send it directly.

Questions about this notice can be sent to [bcperf@gmail.com](mailto:bcperf@gmail.com). The application is provided as-is and this notice may be updated if its data practices change.

**Effective date:** 2026-09-28
